# Security Automation Toolkit

A Python-based command-line toolkit for basic file security operations.

## Features

- **File Hash Calculator** — Generate SHA-256 hash of any file
- **Integrity Check** — Verify if a file has been modified
- **File Information** — Display file metadata (size, permissions, etc.)
- **Security Report** — Generate a comprehensive security report

## Technologies Used

- Python 3
- hashlib (SHA-256)
- os module
- datetime

## How to Use

python toolkit.py

Then select an option from the menu (1-5).
